## Decision

Brand Forged’s **customer-facing / conceptual naming family** is the forge / medieval-tool / protection metaphor — **not** generic software terminology. Functional translations (Identity Engine, Content Studio, CRM, …) remain the engineering/Canon labels; the forge names are the brand language layer that was developed with the founder and then lost from active docs.

### Confirmed names and functions (founder-recovered)

| Name | Represents |
| --- | --- |
| **Sword** | Branding, identity, creative work, and discovery |
| **Citadel** | Business, software, systems, and the central operational hub |
| **Shield** | Security, legal protection, safeguards |
| **Anvil** | Where work comes together — projects, execution, building, manufacturing, launching, publishing |
| **Foundry** | The place/system where creation and transformation happens |
| **Whetstone** | Refinement, improvement, sharpening, optimization |
| **Vault** | Financial / protected valuable resources *(product metaphor; distinct from institutional “Brand Vault” authority store unless Strategy Room merges them)* |
| **Scabbard** | Structuring, containing, organizing, and integrating |

**Provenance note:** Recovered personal context records the original **Sword, Citadel, Shield, Whetstone, Vault, Scabbard** proposal, then **Anvil** added for execution/building/manufacturing/launching/publishing. **Foundry** is included in the recovered final set as the creation/transformation place.

### Conceptual architecture (likely; not proven as final UI order)

```
BRAND FORGED
  → Sword      — create / shape identity
  → Foundry    — create / transform
  → Anvil      — build / execute
  → Whetstone  — refine
  → Scabbard   — organize / integrate
  → Citadel    — operate / manage
  → Shield     — protect
  → Vault      — safeguard value
```

**Honest gap:** Names + most functions are confirmed. Exact final ordering and home/interface layout are **not** recovered. Do not treat the sequence above as shipped IA until founder locks layout.

| Door (001) | Natural forge gravity (provisional mapping) |
| --- | --- |
