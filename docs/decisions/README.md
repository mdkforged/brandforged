# Decision Records

Use this directory for durable architecture and product decisions that future contributors should be able to understand without relying on chat history.

Decision records should be concise and include:

- the date of the decision;
- the context that made the decision necessary;
- the decision that was made;
- the consequences or tradeoffs accepted;
- links to related milestones or implementation notes when available.

Prefer naming decision files with a sortable numeric prefix, for example `0001-repository-architecture.md`.
