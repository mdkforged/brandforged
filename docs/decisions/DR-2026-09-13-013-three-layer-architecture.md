**Status:** Locked

## Decision

Adopt the three-layer operating architecture as official:

1. **Brand Input** — customer Identity Engine intake + Brand Creation Workflow 4.2  
2. **Workflow Routing** — Decision Flow to Constitution / Strategy Room / Master Playbook / Build Lab / Project Documentation / Brand Vault  
3. **Implementation Gate** — own document → scope → version → implement  

Never conflate Brand Input questions with Routing questions or with governance debate.
