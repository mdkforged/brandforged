# Knowledge

This directory is the home for durable Brand Forged knowledge that guides product, engineering, content, and operational decisions.

Use this space for materials such as:

- constitutional project principles;
- implementation and design standards;
- repeatable playbooks;
- reusable prompts;
- long-lived research or reference notes.

Do not use this directory for runtime application code. Marketing copy may be added under `knowledge/marketing/` in a future milestone when that content is needed.
